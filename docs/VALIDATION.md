# Проверка 0.4.2

15 октября 2026. Изменены только мастер обслуживания и восстановление установки;
игровые расчёты не менялись.

## Исправленные причины

- Ошибка записи отчёта от 15:37 относится к старому 0.4.0; исправление атомарного
  статуса из 0.4.1 сохранено.
- Ошибки «Выберите пустую папку» после этого вызваны остатками Data/Cache/Work и
  setup.log без маркера принадлежности. Состояние подтверждено в старой папке W:.
- Для точно распознанных остатков старого установщика разрешён повтор установки.
  Чужие непустые папки отклоняются. Маркер нового запуска сохраняется до распаковки.
  Старые данные, журнал и резервные копии не удаляются.
- Текущая ошибка worker передаётся в окно; история setup.log не используется как
  результат последней операции.
- Результат фоновой проверки папки возвращается через Dispatcher, в том числе при
  создании окна до запуска UI message loop.

## Проверки

- 42 целевые проверки: прежние контракты, атомарный статус, распознавание остатков
  0.4.0, отказ для посторонних файлов, повтор после маркера, стандартная папка.
- Все этапы установщика и удалятора отрендерены при 100/150/200%. Обложка отсутствует
  после приветствия. Проверены полные встроенные лицензии и красная выключенная
  кнопка до согласия. Рендеры прогресса используют заданное тестовое значение 62%,
  а не являются отчётом об установке.
- Стандартная папка: %LOCALAPPDATA%\Programs\DivineLabs\Idle Slayer Mods.
  Разработка, сборки и тестовые установки остаются в W:\DEV.
- Переходы 200 мс, ход выполнения 180 мс; повторное действие заменяет анимацию.
  В режиме уменьшенных анимаций переходы отключаются.

Финальный EXE 0.4.2: scripts/CheckInstallerProgress.ps1 прошёл восстановление
старой прерванной установки с заблокированным отчётом, обновление с 737 чтениями
статуса и синхронное удаление внешним worker. Пользовательский файл сохранён
после обновления и удаления. Проверка выполнена без изменения ярлыков/реестра.
Отдельный запуск в чужую непустую папку вернул код 2 и сообщение текущей ошибки
через отчёт; посторонний файл сохранён.

CheckPortable.ps1: состав ZIP, запуск проверки через корневой EXE, перенос
с пробелами и кириллицей, расположение Data и возврат ошибки прошли.

## Локальное исправление запуска после 0.4.2

При прямом диагностическом запуске подтверждён XamlParseException в анимации
номера этапа: путь RenderTransform.ScaleX/ScaleY не разрешался при создании окна.
Прежняя проверка макетов отключала анимации и не выявляла этот сбой.
Анимация заменена коротким изменением Opacity без вложенного пути свойств.
В tests/Layout добавлен параметр --animations; все этапы установщика и удалятора
при 100/150/200% прошли построение с включёнными анимациями.
Ненулевой код дочернего интерфейса теперь приводит к записи stderr в журнал
и понятному сообщению от NativeAOT-загрузчика вместо тихого завершения.
Исправленный локальный комплект: W:\DEV\artifacts\DivineLabs_IdleSlayer_Mods\icon-refresh.
Это не повторная публикация релиза 0.4.2.
Прямой запуск исправленного готового EXE подтверждён: дочерний процесс остаётся
работающим, Windows Computer Use видит окно DivineLabs Idle Slayer Mods, приветствие,
пять этапов и доступную кнопку «Далее». Окно оставлено открытым пользователю.
Это подтверждение запуска, а не ручная приёмка всех действий мастера.

## Ресурсы и бесплатные покупки · 16 октября 2026

Предварительная локальная сборка `resources-preview`, исходники после 0.4.2.
Публичный стабильный выпуск этим изменением не объявлен.

Выполнено:

- Mod (net6.0) и автономный Launcher (net10.0-windows/win-x64) собраны без
  предупреждений и ошибок. Проверена указанная в CURRENCY-CAPABILITIES сборка игры.
- Checks завершились успешно при закрытой игре: старые проверки плюс валидация
  разовых команд, переполнение/округление, граница формулы USP, миграция пяти
  выключенных функций, повтор ID, другой payload с тем же ID, старая сессия,
  перезапуск хоста и устаревшая ревизия. Запуск Checks при открытой игре был
  остановлен штатной защитой установки; после закрытия полный прогон прошёл.
- Все четыре страницы лаунчера построены при 100/150/200% (12 PNG). Это
  RenderTargetBitmap с разной плотностью, не переключение системного DPI.
- Игра прошла титульный экран/синхронизацию и вошла в Game с новыми патчами.
- В игровой сессии выданы SP +1, DP +1, USP +1, камень душ +1 и материал +1;
  сохранение сверено игровым API с файлом. Повтор команды возвращал квитанцию.
- Монетная выдача не умножалась повторно. Первый диагностический прогон обнаружил
  расхождение точного double и штатной записи G15; проверка исправлена. Отдельная
  новая монетная команда прошла сверку файла и буфера. Исходная команда не
  отправлялась повторно как новая выдача.
- После полного перезапуска баланс камней и earned сохранились. Purchased и
  Purchases остались прежними. Это не проверка платёжной транзакции.
- Включены пять режимов: проверены нулевые цены оборудования/максимальной пачки,
  SP, DP, USP и требования постоянного крафта. Через штатный обработчик кнопки
  куплен один уровень оборудования без списания монет.
- Удалён несовместимый GetSceneByName (IL2CPP ReadOnlySpan); повторное чтение
  ресурсов и построение меню на исправленной сборке прошли без исключений.
  Готовность/копия для покупок сбрасываются по выгрузке Game, Canvas скрываются.
- Создано игровое меню ресурсов, снимок осмотрен. Исходные настройки возвращены;
  сохранения не откатывались. Пробные ресурсы и купленный уровень остаются.
- Диагностический мод не включается в portable; Package.ps1 отклоняет и его имя.

Диагностические отчёты и снимки: `W:\DEV\artifacts\DivineLabs_IdleSlayer_Mods\resources-runtime`.
Первые прогоны/ошибки сохранены в отчёте, а не удалены. Диагностический мод
включал runInBackground и штатный обработчик перехода с титульного экрана;
эти действия не добавлены в продукт. Принудительное завершение было отклонено
автопроверкой разрешений и не выполнялось: использовалось обычное закрытие.

Осталось неподтверждённым:

- Фактические покупки SP/DP/USP/рецептов, компенсация DP/USP в пользовательском
  сценарии, временный крафт пачкой, отдельные операции кузницы и деревни.
- Локальное расходование камней на каждый вид товара, принятие облачным сервером,
  перенос на другое устройство, восстановление покупок и серверные товары.
- Физические клики/ввод в новых экранах и сочетания новых функций; прежние
  пользовательские ответы о F8 относятся к прошлому интерфейсу.
- Отдельный полный переход Game → титульный экран → Game с сохранением
  открытой панели не проверен (обычное завершение тестового процесса проверено).
- Нагрузка/FPS нового кода и реальная смена DPI. Широкие игровые сценарии,
  повторная установка/удаление и новая машина без .NET в этой задаче не запускались.

## Android-порт · 16 октября 2026

Подготовлен исходный порт и сценарии; реальный Android APK игры отсутствует.
10 проверок анализатора/подготовки синтетических APK прошли. Компиляция с
Android Loader v0.7.4-android.3 и диагностическими Steam Unity-прокси прошла
без предупреждений; это не игровые Android DLL для поставки. Android Contracts
не содержит Windows IPC, собственные Android-сборки не содержат user32/kernel32
P/Invoke. Windows Mod после условного разделения собирается.

Настоящие Android Interop, готовый APK, установка, сенсорные сценарии, хуки,
сохранения/облако и производительность не проверены. Нельзя считать Windows
результаты выше доказательством Android-совместимости. Подробности: android/README.ru.md.
