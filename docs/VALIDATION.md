# Проверка 0.4.1

Дата: 15 октября 2026. Выпуск исправляет установщик 0.4.0 и его оформление.

## Причина ошибки и исправление

Интерфейс читал operation-*.txt через File.ReadAllLinesAsync, а worker одновременно
вызывал File.WriteAllText. Конфликт доступа из Report выходил в Install и приводил
к отказу/откату установки.

Теперь статус публикуется отдельным временным файлом и File.Replace, а читатель
открывает его с FileShare.ReadWrite | FileShare.Delete. Временная недоступность
статуса пропускается; отчёт о прогрессе не определяет успех операции. Интерфейс
показывает результат после завершения worker с успешным кодом.

## Проверки

- 37 проверок расчётов, настроек, локального канала и установки; в том числе
  заблокированный читатель статуса, разрешённая атомарная замена, параллельное
  чтение/запись и доступность финального статуса.
- WPF-представления всех пяти этапов установки и четырёх этапов удаления
  отрендерены при 100/150/200%. Проверены обязательное согласие с лицензией,
  наличие встроенного полного текста, состояния кнопок и отсутствие обрезания.
- Компоновка лаунчера проверена с общими стилями и новым знаком DivineLabs.
- Самостоятельный прогон реального NativeAOT EXE с постоянно заблокированным
  файлом прогресса и повторное обновление с частым чтением:
  scripts/CheckInstallerProgress.ps1. Результат прогона фиксируется ниже
  после финальной сборки.

## Границы подтверждения

Рендеры WPF не заменяют реальное переключение DPI Windows или ручной проход мышью.
Интерактивный мастер нужно подтвердить на финальном комплекте. Ручные игровые
проверки Insert, виджета, переназначения и ввода остаются открытыми по списку
из чата. В 0.4.1 игровые расчёты не менялись, обновлены знак и надписи.
Заявления о новой игровой сессии, длительном тесте утечек или чистой машине
без установленного .NET не делаются.

История игровых проверок 0.4.0 сохранена в VALIDATION-0.4.0.md.

## Результат финального комплекта

- Финальный NativeAOT Setup завершил установку с постоянно открытым читателем,
  который запрещает запись/удаление отчёта прогресса.
- Повторное обновление с опросом раз в 10 мс завершилось успешно:
  получено 637 полных статусов. Пользовательский файл настроек сохранился.
- Worker удаления запущен из отдельной папки; к моменту успешного выхода
  EXE программы уже отсутствовал, данные остались.
- Финальный portable прошёл проверку состава, запуск проверки комплекта,
  перенос с пробелами/кириллицей и возврат кода ошибки с журналом.
- Метаданные Setup, стартового EXE и Launcher: DivineLabs Idle Slayer Mods,
  версия 0.4.1.0. Сверены байты встроенной иконки Setup 256px с исходником.
- Исходники загрузчика не изменялись; использованы закреплённые ранее собранные
  бинарные файлы форка. Собственные проекты пересобраны.
