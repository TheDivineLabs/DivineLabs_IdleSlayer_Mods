## 0.5.3

Добавлен флажок **«Полное удаление, включая данные программы»** в удалятор и подтверждение удаления лишней копии.

Без флажка данные сохраняются. С флажком удаляется также вся папка `Data` выбранной установки: настройки, кэш, журналы и резервные копии. Оригинальные сохранения в папке игры и посторонние файлы вне `Data` не затрагиваются.

- **DivineLabs.Idle.Slayer.Mods.exe** — установщик.
- **DivineLabs-IdleSlayer-0.5.3-portable.zip** — готовая переносимая версия.

Windows x64, Steam, Idle Slayer 7.3.4 / сборка 25810322. Игровые компоненты — 0.5.0; отдельно устанавливать .NET не нужно.
