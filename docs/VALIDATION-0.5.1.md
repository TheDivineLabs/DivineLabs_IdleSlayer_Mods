# Проверка 0.5.1 · 17 октября 2026

Область изменения: настольная оболочка и удаление лишней копии из списка
установок. Версии приложения и игровых компонентов разделены: 0.5.1 / 0.5.0.

## Выполнено

- Сборка Launcher/WPF и NativeAOT Setup/Bootstrap из канонического репозитория.
  `scripts/Build-DesktopRelease.ps1` проверяет SHA256 исходного portable 0.5.0,
  всех файлов его игровых компонентов и служебного архива; игровые DLL повторно
  не собираются. Старые комплекты сохранены.
- `tests/CopyRemoval`: удаление выбранной установки, сохранение Data, настроек,
  сохранений, резервных копий и пользовательских файлов внутри/вне Docs,
  изоляция каталога другой копии. Нормализованный путь в Data и каталог-ссылка
  отклоняются до удаления файлов. Занятый файл не вызывает частичного удаления;
  после освобождения повтор проходит. Запущенная тестовая копия отклоняется.
- `tests/Layout --copy-removal-check`: показанное окно WPF, поиск двух тестовых
  копий, выбор папки без старта установки, подтверждение полного пути и отмена,
  ошибка занятого файла и повтор через настоящий NativeAOT worker. Проверены
  блокировка кнопок мастера и закрытия, снятие блокировки после завершения,
  удаление строки только после успеха. Проверены все 247 текстовых ключей
  девяти языков; получены рендеры светлой и тёмной темы.
- `scripts/Check-CopyRemoval.ps1`: две полноценные автономные установки в
  уникальной папке W:\DEV\.cache\temp, удаление только выбранной,
  сохранение шести контрольных пользовательских файлов. SHA256 лаунчера второй
  копии не меняется; её корневой EXE успешно выполняет `--verify-package`
  с DOTNET_ROOT на несуществующую папку и отключённым multilevel lookup.
- Portable: состав корня App / Docs / EXE, отсутствие PDB и игровых исходных DLL,
  запуск проверки комплекта и перенос в папку с пробелами/кириллицей.
- Проверка Git diff, версий и контрольных сумм публикуемых архивов.

Свидетельства сохраняются рядом с финальным комплектом в
`W:\DEV\artifacts\DivineLabs_IdleSlayer_Mods\0.5.1\Checks`.
Реальные пользовательские установки не удалялись; тесты используют отдельные
папки. Игровые компоненты при удалении копии не отключаются.

## Границы подтверждения

События WPF и рендеры не подтверждают физический ввод мышью/клавиатурой.
Новый игровой прогон и Android не выполнялись: игровые компоненты не менялись.
Изолированная установка проверена без интеграций, чтобы не менять рабочие ярлыки
и текущую запись Windows. Общие ярлыки при удалении отдельной копии сохраняются.

NuGet сообщил NU1900: сведения об уязвимостях источников nuget.org/bepinex были
недоступны. Это предупреждение сборки, а не пройденный аудит зависимостей.
Выпуск сохраняет предварительный статус 0.5.0.
