# DivineLabs Idle Slayer Mods

Mod launcher for Idle Slayer on Windows. Manage game modifications, settings and the in-game menu.

## Download

**[Installer](https://github.com/TheDivineLabs/DivineLabs_IdleSlayer_Mods/releases/latest/download/DivineLabs.Idle.Slayer.Mods.exe)** · **[Portable ZIP](https://github.com/TheDivineLabs/DivineLabs_IdleSlayer_Mods/releases/latest/download/DivineLabs-IdleSlayer-0.5.3-portable.zip)**

Windows x64 · Steam · Idle Slayer 7.3.4 (build 25810322). No separate .NET installation required.

![DivineLabs Idle Slayer Mods](assets/screenshots/launcher.png)

Launcher, installer and uninstaller: nine languages. In-game menu: Russian.

## Features

- Coin, damage and soul multipliers.
- Resource grants: coins, SP, DP, USP and materials.
- Free purchases with in-game resources.
- In-game menu, draggable widget and active features list.

## Getting started

1. Install Idle Slayer through Steam.
2. Run the installer, or extract the portable ZIP and open `DivineLabs.IdleSlayer.exe`.
3. Open the launcher and click **Play**. Press **Insert** in game to open the menu.
