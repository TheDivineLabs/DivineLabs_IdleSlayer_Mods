# DivineLabs Idle Slayer Mods 0.5.1 · Windows x64 / Steam

В установщике: **Параметры → Другие установки программы → Удалить копию**.
Перед удалением показывается полный путь. Удаляются только файлы выбранной
программы из её списка установки. Настройки, сохранения, резервные копии и
посторонние файлы остаются в прежней папке. Моды в игре не отключаются,
другие установки сохраняются. Запущенную копию сначала нужно закрыть.

При ошибке доступны журнал и повторная попытка. Во время удаления нельзя
закрыть мастер или одновременно начать установку. Копия исчезает из списка
после подтверждённого завершения операции.

В выпуск также вошли изменения настольного интерфейса из предыдущих
предварительных сборок: светлая, тёмная и системная темы, девять языков,
выбор страны, мастер удаления в общем стиле и `DivineLabs.Uninstall.exe`
в корне установленной программы. Собственный код DivineLabs — MIT;
лицензии зависимостей сохранены.

## Скачать

- **DivineLabs Idle Slayer Mods.exe** — автономный установщик.
- **DivineLabs-IdleSlayer-0.5.1-portable.zip** — распаковать целиком и открыть
  `DivineLabs.IdleSlayer.exe`.
- **DivineLabs-IdleSlayer-0.5.0-components.zip** — служебный архив для восстановления,
  отдельной установки не требует.

Внешний .NET не нужен. Игровые компоненты остались версии **0.5.0**, их файлы
проверены по SHA256 и не изменялись. Совместимость игры прежняя: Idle Slayer 7.3.4,
Steam build 25810322. Новых игровых функций в этом выпуске нет.

## Проверено

Удаление одной из двух тестовых установок, сохранение настроек/сохранений/резервных
копий и пользовательских файлов, работа оставшегося EXE и проверка его комплекта.
Проверены подтверждение и отмена через события WPF, занятый файл, повторная
попытка, блокировка закрытия, каталог установок и отказ от удаления через ссылки.

Физические клики и новый игровой прогон этой сборки не проводились. Выпуск
сохраняет предварительный статус 0.5.0. Подробности: `docs/VALIDATION-0.5.1.md`.
