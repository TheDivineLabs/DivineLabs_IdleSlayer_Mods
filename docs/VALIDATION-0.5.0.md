# Проверка ПК-выпуска 0.5.0

Область: Windows x64, Steam Idle Slayer 7.3.4 / build 25810322.
Предварительный выпуск; Android не входит в дистрибутивы.

## Выполнено на комплекте 0.5.0

- scripts/Build.ps1 собрал форк загрузчика, Mod, автономный WPF Launcher,
  корневой NativeAOT EXE, portable ZIP и NativeAOT Setup. Внешняя папка анализа
  в ссылках собственных проектов не используется. Все результаты находятся в W:\DEV.
- 57 существующих Checks прошли: конфигурация, миграция, большие множители,
  переполнение, округление начислений, ограничение USP, повтор команд, устаревшие
  сессии/ревизии, загрузка по SHA256, миграция установки и откат компонентов.
- Layout с --animations: 39 PNG страниц лаунчера, установщика и удалятора
  при 100/150/200%. Проверены построение с анимациями, согласие с лицензиями
  и наличие встроенного текста лицензии. Визуально осмотрены приветствие и ресурсы.
  Это рендер с разной плотностью, а не переключение системного DPI Windows.
- Архивы: CRC всех записей, отсутствие повторов/небезопасных путей, совпадение
  версии 0.5.0 и всех 386 компонентов с SHA256 манифеста. Portable: 412 записей,
  components: 388. Игровых DLL/метаданных, Android APK, сохранений, ключей,
  диагностических модов и PDB в комплекте нет.
- CheckPortable.ps1: запуск готового корневого EXE, проверка встроенных компонентов,
  перемещение с кириллицей и пробелами, расположение Data и возврат ошибки.
- CheckInstaller.ps1 на окончательном EXE: миграция 0.2.0, чистый корень,
  запуск проверки комплекта, обновление, тихое удаление и повторная установка.
  Пользовательские настройки, файлы и маркер принадлежности сохранились.
- CheckInstallerProgress.ps1 на окончательном EXE: восстановление прерванной
  установки при заблокированном отчёте, обновление с 619 чтениями статуса,
  удаление внешним worker до подтверждения успеха. Пользовательский файл сохранён.
- ProductVersion корневого EXE, Launcher и Setup — 0.5.0;
  ProductName — DivineLabs Idle Slayer Mods.

Установка/удаление проверялись с --no-integrations / --files-only, без изменения
ярлыков, реестра и рабочей установки игры. Portable содержит автономный .NET;
Bootstrap и Setup — NativeAOT. Новая чистая Windows без установленного .NET
отдельно не проверялась. Автоматическое скачивание опубликованного components.zip проверено после
публикации; результаты приведены ниже.

## Ошибка первого цикла и исправление

Первая CheckInstaller начинала повторную установку после исчезновения корневого
EXE, хотя фоновая очистка ещё продолжалась. Установка и удаление пересеклись:
очистка сообщила об оставшихся файлах, установка — о занятом файле.

Тихое удаление теперь передаёт --report фоновой очистке, которая публикует
100 только после фактического удаления либо -1 при ошибке. Проверка ждёт этот
финальный результат. Изменённый Setup пересобран отдельно; обе проверки установки
повторены успешно. Неудачный первый EXE и его журналы сохранены локально.

## Предупреждения сборки

В форке загрузчика сохранены NU1701 для Microsoft.Bcl, CS0168/CS0219,
CA2200 и IL3050/IL3053 для сериализации Tomlet в NativeAOT. Ошибок сборки нет.
Собственные Mod/Launcher/Bootstrap/Setup собраны без предупреждений.
Полный журнал сохраняется локально; нулевые предупреждения всего форка не заявляются.

## Границы игровой проверки

Игровые результаты ресурсов получены в предыдущем целевом прогоне того же
Windows-кода: выдача и сверка сохранений, сохранение камней после перезапуска,
покупка уровня оборудования без списания монет. Ссылки и детали — в
[историческом журнале](VALIDATION.md#ресурсы-и-бесплатные-покупки--16-октября-2026).
В этой подготовке релиза новая игровая сессия не запускалась.

Не подтверждены физический ввод/перетаскивание нового меню, полный ручной проход
мастера, реальная смена DPI, FPS и выделения памяти, покупки SP/DP/USP/рецептов,
все товары за камни и перенос облачного баланса. Стабильная приёмка всех новых
функций не заявляется. [Охват функций](CURRENCY-CAPABILITIES.ru.md).
