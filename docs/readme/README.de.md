# DivineLabs Idle Slayer Mods

Mod-Launcher für Idle Slayer unter Windows. Verwalte Spielmodifikationen, Einstellungen und das Menü im Spiel.

## Download

**[Installationsprogramm](https://github.com/TheDivineLabs/DivineLabs_IdleSlayer_Mods/releases/latest/download/DivineLabs.Idle.Slayer.Mods.exe)** · **[Portable ZIP](https://github.com/TheDivineLabs/DivineLabs_IdleSlayer_Mods/releases/latest/download/DivineLabs-IdleSlayer-0.5.3-portable.zip)**

Windows x64 · Steam · Idle Slayer 7.3.4 (Build 25810322). Eine separate .NET-Installation ist nicht nötig.

![DivineLabs Idle Slayer Mods](../../assets/screenshots/launcher.png)

Launcher, Installation und Deinstallation: neun Sprachen. Menü im Spiel: Russisch.

## Funktionen

- Multiplikatoren für Münzen, Schaden und Seelen.
- Ressourcen hinzufügen: Münzen, SP, DP, USP und Materialien.
- Kostenlose Käufe mit Spielressourcen.
- Menü im Spiel, verschiebbares Widget und Liste aktiver Funktionen.

## Erste Schritte

1. Installiere Idle Slayer über Steam.
2. Starte das Installationsprogramm oder entpacke das portable ZIP und öffne `DivineLabs.IdleSlayer.exe`.
3. Öffne den Launcher und klicke auf **Spielen**. Mit **Einfg** öffnest du das Menü im Spiel.
