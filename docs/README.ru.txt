DivineLabs Idle Slayer Mods 0.5.3

Мод-лаунчер для Idle Slayer на Windows x64 / Steam.
Поддерживаемая игра: Idle Slayer 7.3.4, Steam-сборка 25810322.
Отдельно устанавливать .NET не нужно.

Начало работы
Установите Idle Slayer через Steam. Откройте DivineLabs.IdleSlayer.exe и нажмите
«Играть». Insert открывает меню в игре; клавишу можно изменить в настройках.

Функции
Множители монет, урона и душ; выдача ресурсов; бесплатные покупки за игровые
ресурсы; перетаскиваемый виджет и список активных функций.
Лаунчер, установщик и удалятор: девять языков. Игровое меню: русский.

Файлы и удаление
App — файлы программы. Data — настройки, журналы, кэш и резервные копии.
Docs — инструкции и лицензии.
В установленной версии откройте DivineLabs.Uninstall.exe в основной папке.
На этапе «Параметры» раздел «Другие установки программы» позволяет удалить
лишние копии. По умолчанию настройки, сохранения и резервные копии остаются.
Флажок «Полное удаление, включая данные программы» также удаляет всю папку Data
выбранной установки: настройки, кэш, журналы и резервные копии без восстановления.
Оригинальные сохранения в папке игры и посторонние файлы вне Data остаются.
Удаление отдельной копии не отключает моды в игре. Перед удалением закройте
приложения из выбранной копии. Portable перемещайте целиком после закрытия.
Игровые настройки: UserData/DivineLabs.settings.json в папке игры.
