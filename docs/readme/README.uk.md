# DivineLabs Idle Slayer Mods

Мод-лаунчер для Idle Slayer на Windows. Керування ігровими модифікаціями, налаштуваннями та меню в грі.

## Завантажити

**[Інсталятор](https://github.com/TheDivineLabs/DivineLabs_IdleSlayer_Mods/releases/latest/download/DivineLabs.Idle.Slayer.Mods.exe)** · **[Portable ZIP](https://github.com/TheDivineLabs/DivineLabs_IdleSlayer_Mods/releases/latest/download/DivineLabs-IdleSlayer-0.5.2-portable.zip)**

Windows x64 · Steam · Idle Slayer 7.3.4 (збірка 25810322). Окремо встановлювати .NET не потрібно.

![DivineLabs Idle Slayer Mods](../../assets/screenshots/launcher.png)

Лаунчер, інсталятор і деінсталятор: девʼять мов. Ігрове меню: російська.

## Функції

- Множники монет, шкоди та душ.
- Видача ресурсів: монети, SP, DP, USP і матеріали.
- Безкоштовні покупки за ігрові ресурси.
- Ігрове меню, віджет із перетягуванням і список активних функцій.

## Початок роботи

1. Установіть Idle Slayer через Steam.
2. Запустіть інсталятор або розпакуйте portable ZIP і відкрийте `DivineLabs.IdleSlayer.exe`.
3. Відкрийте лаунчер і натисніть **Грати**. Клавіша **Insert** відкриває меню в грі.
