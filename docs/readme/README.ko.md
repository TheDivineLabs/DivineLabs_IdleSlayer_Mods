# DivineLabs Idle Slayer Mods

Windows용 Idle Slayer 모드 런처입니다. 게임 모드, 설정 및 게임 내 메뉴를 관리합니다.

## 다운로드

**[설치 프로그램](https://github.com/TheDivineLabs/DivineLabs_IdleSlayer_Mods/releases/latest/download/DivineLabs.Idle.Slayer.Mods.exe)** · **[포터블 ZIP](https://github.com/TheDivineLabs/DivineLabs_IdleSlayer_Mods/releases/latest/download/DivineLabs-IdleSlayer-0.5.3-portable.zip)**

Windows x64 · Steam · Idle Slayer 7.3.4 (빌드 25810322). .NET을 따로 설치할 필요가 없습니다.

![DivineLabs Idle Slayer Mods](../../assets/screenshots/launcher.png)

런처, 설치 및 제거 프로그램: 9개 언어. 게임 내 메뉴: 러시아어.

## 기능

- 코인, 피해량 및 영혼 배율.
- 자원 지급: 코인, SP, DP, USP 및 재료.
- 게임 내 자원을 사용하는 무료 구매.
- 게임 내 메뉴, 드래그 가능한 위젯 및 활성 기능 목록.

## 시작하기

1. Steam에서 Idle Slayer를 설치하세요.
2. 설치 프로그램을 실행하거나 포터블 ZIP을 압축 해제한 뒤 `DivineLabs.IdleSlayer.exe`를 여세요.
3. 런처를 열고 **플레이**를 누르세요. 게임에서 **Insert** 키로 메뉴를 열 수 있습니다.
