# DivineLabs IdleSlayer Mods

Собственные лаунчер и модификации Idle Slayer для Windows x64 / Steam. Монеты и урон, настройки до запуска, игровое меню F8. Игра не входит в поставку.

## Запуск

Распакуйте переносимый комплект под `W:\DEV`, запустите `DivineLabs.IdleSlayer.exe`, выберите установку игры и нажмите «Установить / обновить». Затем «Играть»: запуск выполняется через Steam. Установленную папку лаунчера не перемещайте: игровые папки подключены к её `Data/runtime` через junction.

Пока игра работает, настройки лаунчера доступны только для чтения. F8 открывает меню в игре. Положительный доход умножается, отрицательные списания не меняются. Охват урона — `EnemyGameObject.TakeDamage`; отдельные механики боссов не заявлены. Значения от 1 до 1 000 000. Настройки сохраняются сразу после применения.

«Запустить без модов» временно отключает компоненты. «Вернуть прошлую установку» восстанавливает предыдущие файлы. Сохранения игры автоматически не откатываются. Резервные копии прогресса хранятся в `Data/save-backups`; прежние установки — в `.divinelabs-history` рядом с игрой. Старые копии не удаляются.

## Сборка

Требования: .NET 10 SDK, Windows C++ Build Tools для NativeAOT, установленная игра с уже сгенерированными локальными IL2CPP-сборками MelonLoader 0.7.3. Первый запуск загрузчика генерирует их; игра и её сборки в Git не включены.

```powershell
./scripts/Build.ps1 -GamePath 'W:\steam\steamapps\common\Idle Slayer' -Dotnet 'W:\DEV\tools\dotnet\dotnet.exe'
dotnet run --project tests/Checks.csproj -c Release
```

Для перенесённого C++ toolchain доступны `-NativeBin` и `-NativeLib`. `-SkipLoader` использует уже собранный форк. Архивировать для распространения следует только файлы переносимого комплекта и `payload`, исключая `Data` с настройками, журналами и резервными копиями.

## Устройство

- `src/Launcher`: WPF / .NET 10; Steam, установка и откат.
- `src/Mod`: C# / .NET 6, uGUI + TextMeshPro, игровые патчи.
- `src/Contracts`: JSON v1, валидация, атомарная запись, восстановление.
- `loader`: исходники адаптированного MelonLoader; ревизия в `loader/UPSTREAM.txt`.
- `tests`: проверки покупок, конфигурации, блокировки записи и отключения установки.

Проверенная сборка игры: Steam 25810322, Unity 6000.3.14f1. При другом SHA256 патчи не включаются; используйте обычный запуск до проверки совместимости.

## Лицензии и диагностика

Собственный код DivineLabs — Apache-2.0. Форк MelonLoader сохраняет исходные NOTICE и лицензию. Другие компоненты перечислены в `THIRD-PARTY-NOTICES.txt`. Коллекция legovader09 не включена, её Core DLL не используется.

Пользовательские сообщения — на русском. Консоль адаптированного загрузчика переводит штатные сообщения и показывает русскую сводку для нераспознанной диагностики; исходные технические строки сохраняются в `MelonLoader/Latest.log`. Это не перевод текста Unity и системных исключений.

## Проверка выпуска 0.1.0

На Windows x64 со Steam-сборкой 25810322 проверены:
- сборка лаунчера, мода и нативного/управляемого форка загрузчика;
- расчёты дохода и расходов, переполнение, импорт, резервный JSON и блокировка записи;
- установка из переносимого комплекта, отключение/включение и двойной возврат между установками;
- запуск кодом лаунчера через Steam, облачная синхронизация и игровая сцена;
- реальные обработчики настроек, покупка за обычную цену при ×100, урон ×1000 на активном враге;
- вид меню с кириллицей при 1920×1080 и 960×600.

Физические клики, ввод текста с клавиатуры и переключение F8 требуют отдельного подтверждения: Windows Graphics Capture в среде проверки возвращал тайм-аут. Программный вызов обработчика не заменяет эту проверку. До подтверждения сборка считается предварительной.

Диагностический проект `tests/Probe` не входит в дистрибутив. Он выполняет одну настоящую покупку доступного улучшения и тестовый удар; запускайте его только для явной проверки на сохранении с резервной копией. Исходные коэффициенты и размер окна восстанавливаются, прогресс игры не откатывается.

Упаковка без пользовательской папки `Data`:

