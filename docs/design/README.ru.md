# Обзор дизайна установщика

Снимки снимаются из текущего WPF-интерфейса, а не воссоздаются вручную.
Программа не устанавливается: прогресс 62% и результат — демонстрационные состояния.
Галерея — средство обсуждения снимков. Она не редактирует дизайн приложения:
PNG не содержит редактируемых текстовых/векторных слоёв.

## Снять новую ревизию

Из корня репозитория:

~~~powershell
./scripts/design/Export-InstallerReview.ps1 -Output 'W:\DEV\artifacts\DivineLabs_IdleSlayer_Mods\installer-review-r02'
~~~

Для каждой ревизии выбирайте новую папку: старый ZIP и снимки сохраняются.
Скрипт собирает Layout, снимает интерфейс при 100/150/200% и экспортирует
пять экранов в 100% и 200%, исходники интерфейса и графику. В архив не входит raw.
В manifest.json записываются ревизия Git и SHA256 снимков/исходников.
Исходники в Sources — часть основного проекта, а не самостоятельное приложение.

Откройте index.html в обычном браузере. Можно пользоваться без сервера и подписок.
«Отметить правку» добавляет точку и текст. Заметки хранятся только в браузере;
скачайте JSON для передачи. Импорт заменяет текущие заметки, сначала экспортируйте
нужные. Между ревизиями положения точек могут сместиться относительно элементов.

После обсуждения меняйте реальные MaintenanceWindow.xaml и SetupTheme.xaml
с их общими ресурсами в src; затем снимайте новую ревизию той же командой.
Это сохраняет соответствие программы и обзора. Для облачных редактируемых
макетов отдельно нужна подключённая интеграция Figma; эта галерея ничего туда
не загружает.
