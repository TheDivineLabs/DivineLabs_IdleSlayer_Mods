# Проверка 0.4.2

15 октября 2026. Изменены только мастер обслуживания и восстановление установки;
игровые расчёты не менялись.

## Исправленные причины

- Ошибка записи отчёта от 15:37 относится к старому 0.4.0; исправление атомарного
  статуса из 0.4.1 сохранено.
- Ошибки «Выберите пустую папку» после этого вызваны остатками Data/Cache/Work и
  setup.log без маркера принадлежности. Состояние подтверждено в старой папке W:.
- Для точно распознанных остатков старого установщика разрешён повтор установки.
  Чужие непустые папки отклоняются. Маркер нового запуска сохраняется до распаковки.
  Старые данные, журнал и резервные копии не удаляются.
- Текущая ошибка worker передаётся в окно; история setup.log не используется как
  результат последней операции.
- Результат фоновой проверки папки возвращается через Dispatcher, в том числе при
  создании окна до запуска UI message loop.

## Проверки

- 42 целевые проверки: прежние контракты, атомарный статус, распознавание остатков
  0.4.0, отказ для посторонних файлов, повтор после маркера, стандартная папка.
- Все этапы установщика и удалятора отрендерены при 100/150/200%. Обложка отсутствует
  после приветствия. Проверены полные встроенные лицензии и красная выключенная
  кнопка до согласия. Рендеры прогресса используют заданное тестовое значение 62%,
  а не являются отчётом об установке.
- Стандартная папка: %LOCALAPPDATA%\Programs\DivineLabs\Idle Slayer Mods.
  Разработка, сборки и тестовые установки остаются в W:\DEV.
- Переходы 200 мс, ход выполнения 180 мс; повторное действие заменяет анимацию.
  В режиме уменьшенных анимаций переходы отключаются.

Финальный EXE 0.4.2: scripts/CheckInstallerProgress.ps1 прошёл восстановление
старой прерванной установки с заблокированным отчётом, обновление с 737 чтениями
статуса и синхронное удаление внешним worker. Пользовательский файл сохранён
после обновления и удаления. Проверка выполнена без изменения ярлыков/реестра.
Отдельный запуск в чужую непустую папку вернул код 2 и сообщение текущей ошибки
через отчёт; посторонний файл сохранён.

CheckPortable.ps1: состав ZIP, запуск проверки через корневой EXE, перенос
с пробелами и кириллицей, расположение Data и возврат ошибки прошли.

## Локальное исправление запуска после 0.4.2

При прямом диагностическом запуске подтверждён XamlParseException в анимации
номера этапа: путь RenderTransform.ScaleX/ScaleY не разрешался при создании окна.
Прежняя проверка макетов отключала анимации и не выявляла этот сбой.
Анимация заменена коротким изменением Opacity без вложенного пути свойств.
В tests/Layout добавлен параметр --animations; все этапы установщика и удалятора
при 100/150/200% прошли построение с включёнными анимациями.
Ненулевой код дочернего интерфейса теперь приводит к записи stderr в журнал
и понятному сообщению от NativeAOT-загрузчика вместо тихого завершения.
Исправленный локальный комплект: W:\DEV\artifacts\DivineLabs_IdleSlayer_Mods\icon-refresh.
Это не повторная публикация релиза 0.4.2.
Прямой запуск исправленного готового EXE подтверждён: дочерний процесс остаётся
работающим, Windows Computer Use видит окно DivineLabs Idle Slayer Mods, приветствие,
пять этапов и доступную кнопку «Далее». Окно оставлено открытым пользователю.
Это подтверждение запуска, а не ручная приёмка всех действий мастера.
