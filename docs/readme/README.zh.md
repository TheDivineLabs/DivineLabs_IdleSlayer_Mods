# DivineLabs Idle Slayer Mods

适用于 Windows 的 Idle Slayer 模组启动器。管理游戏模组、设置和游戏内菜单。

## 下载

**[安装程序](https://github.com/TheDivineLabs/DivineLabs_IdleSlayer_Mods/releases/latest/download/DivineLabs.Idle.Slayer.Mods.exe)** · **[便携版 ZIP](https://github.com/TheDivineLabs/DivineLabs_IdleSlayer_Mods/releases/latest/download/DivineLabs-IdleSlayer-0.5.2-portable.zip)**

Windows x64 · Steam · Idle Slayer 7.3.4（构建 25810322）。无需单独安装 .NET。

![DivineLabs Idle Slayer Mods](../../assets/screenshots/launcher.png)

启动器、安装程序和卸载程序：9 种语言。游戏内菜单：俄语。

## 功能

- 金币、伤害和灵魂倍率。
- 发放资源：金币、SP、DP、USP 和材料。
- 将使用游戏内资源的购买设为免费。
- 游戏内菜单、可拖动的小组件和已启用功能列表。

## 开始使用

1. 通过 Steam 安装 Idle Slayer。
2. 运行安装程序，或解压便携版 ZIP 后打开 `DivineLabs.IdleSlayer.exe`。
3. 打开启动器并点击 **开始游戏**。在游戏中按 **Insert** 打开菜单。
