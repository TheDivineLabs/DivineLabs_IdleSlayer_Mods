# Проверка 0.4.2

15 октября 2026. Изменены только мастер обслуживания и восстановление установки;
игровые расчёты не менялись.

## Исправленные причины

- Ошибка записи отчёта от 15:37 относится к старому 0.4.0; исправление атомарного
  статуса из 0.4.1 сохранено.
- Ошибки «Выберите пустую папку» после этого вызваны остатками Data/Cache/Work и
  setup.log без маркера принадлежности. Состояние подтверждено в старой папке W:.
- Для точно распознанных остатков старого установщика разрешён повтор установки.
  Чужие непустые папки отклоняются. Маркер нового запуска сохраняется до распаковки.
  Старые данные, журнал и резервные копии не удаляются.
- Текущая ошибка worker передаётся в окно; история setup.log не используется как
  результат последней операции.
- Результат фоновой проверки папки возвращается через Dispatcher, в том числе при
  создании окна до запуска UI message loop.
