# Проверка 0.4.0

Дата: 15 октября 2026. Windows x64, Steam Idle Slayer 7.3.4 / build 25810322.

## Подтверждено

- Собственные проекты Launcher, DesktopUI, Contracts, Mod, Bootstrap и Installer собраны без предупреждений и ошибок.
- 32 проверки расчётов, схемы v2, импорта v1, резервных копий, блокировки записи, назначения клавиш, локального протокола, скачивания и установки прошли. Дополнительный тест исключает зависание сохранения на не обслуживаемом игровом SynchronizationContext.
- Рабочая установка обновлена до 0.4.0; проверены комплект и совпадение SHA256 игрового мода с финальным манифестом. Временный AcceptanceProbe удалён из Mods после штатного завершения игры.
- Самодостаточный portable фактически запускался из папки с пробелами и кириллицей до и после переноса. Проверены состав архива, отсутствие PDB и игровых DLL, расположение Data и код ошибки.
- Установщик прошёл миграцию с 0.2.0, повторное обновление, удаление и повторную установку в изолированной папке. Новый синхронный worker удаления отдельно подтвердил возврат успеха только после удаления собственных файлов. Пользовательские файлы и Data сохранены.
- WPF-представления отрендерены при 100%, 150% и 200%; проверены ресурсы, границы, читаемость, установщик и удалятор. Это рендеры компоновки, а не изменение DPI рабочего стола.
- Работающий лаунчер открыл главную и каталог; поиск через доступное поле оставил только соответствующую функцию.
- Игра запущена через лаунчер и Steam, прошла синхронизацию и вошла в сцену Game. Временный проверочный модуль подтвердил создание меню, блокировку игровых обработчиков при открытой панели и отклонение нулевого множителя.
- Реальная покупка через обработчик кнопки магазина увеличила уровень на 1 и списала обычную стоимость при включённом множителе. Урон ×1000 проверен на активном обычном враге. Начальные настройки возвращены через SessionHost; сохранения игры не откатывались.
- Живой протокол изменил клавишу меню и прозрачность в запущенной игре, вернул подтверждённую ревизию и восстановил исходные значения.
- Снимки из Unity подтвердили меню, собственный виджет и расположение после 1920×1080 → 960×600 → 1920×1080.
- В исправленном варианте: открытое меню — 741 кадр, среднее 0,0410 мс, p95 0,0752 мс; закрытое — 797 кадров, среднее 0,0354 мс, p95 0,0808 мс. Это время OnUpdate собственного мода, а не весь рендер Unity/GPU.
- Прямой замер обработчика горячих клавиш в активном игровом окне: 0 выделенных байт на 1000 вызовов после прогрева. Весь OnUpdate: около 44 байт/кадр с открытой панелью и 32 байт/кадр с закрытой; нулевая аллокация всего интерфейса не заявляется.

## Исправления по результатам запуска

Первый игровой кандидат выявил недоступный сгенерированный Unity overload декодирования PNG. Знак теперь строится из собственного векторного контура без этого API. Также устранено использование отсутствующего символа звезды и смещение виджета из-за запаздывания CanvasScaler при изменении разрешения. Повторная проверка была ограничена компоновкой и нагрузкой; покупки и урон повторно не запускались.

## Не подтверждено автоматически

- Физические клики по виджету, его перетаскивание, полный цикл записи сочетания через UI и открытие/закрытие панели физической клавишей Insert требуют отдельного ручного подтверждения.
- Реальное переключение DPI Windows между мониторами и длительный стресс-тест утечек не выполнялись.
- Захват окна инструментом Windows завершался FrameArrived timed out, координатные клики — coordinate input geometry is unavailable. Запрос на запуск интерфейса Setup через Computer Use завершился Computer Use app approval timed out. Его WPF-компоновка и рабочие операции проверены отдельно; интерактивный путь установки/удаления целиком не объявляется подтверждённым.
- Изолированная машина без установленного .NET не использовалась. Комплекты собраны self-contained, NativeAOT-входы фактически запускались.

Проверочный модуль не входит в релиз. История проверки 0.3.1 сохранена в VALIDATION-0.3.1.md.
