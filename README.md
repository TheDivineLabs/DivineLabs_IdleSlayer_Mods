# DivineLabs Idle Slayer Mods

Лаунчер DivineLabs для Idle Slayer на Windows x64 и Steam. Откройте программу: она найдёт игру, подготовит загрузчик и настройки, а недостающие компоненты скачает автоматически. В игре доступно собственное меню Insert с множителями дохода и урона.

Текущие исходники и локальная сборка `W:\DEV\artifacts\DivineLabs_IdleSlayer_Mods\resources-preview`
добавляют множитель душ, большие числа, активный список, прямое перетаскивание,
разовую выдачу монет/SP/DP/USP/материалов/локальных камней душ и пять режимов
бесплатных покупок. Это предварительная сборка после опубликованной 0.4.2.
Проверены реальные начисления и сохранения, перезапуск камней и покупка
оборудования. Остальные границы проверки: [VALIDATION](docs/VALIDATION.md).
[Точный охват валют и покупок](docs/CURRENCY-CAPABILITIES.ru.md).

## Скачать и начать

В [выпуске 0.4.2](https://github.com/TheDivineLabs/DivineLabs_IdleSlayer_Mods/releases/tag/v0.4.2) есть два варианта:

| Вариант | Как использовать |
| --- | --- |
| **DivineLabs Idle Slayer Mods.exe** | Один автономный установщик. Пройдите начало, лицензии и параметры, дождитесь установки и откройте созданный ярлык. Удаление доступно в приложениях Windows. |
| **DivineLabs-IdleSlayer-0.4.2-portable.zip** | Распакуйте весь архив в удобную папку и откройте DivineLabs.IdleSlayer.exe. Устанавливать .NET отдельно не нужно. |

Программа сама проверит комплект и подготовит игру. Когда появится «Всё готово к игре», нажмите «Играть». Если Steam или игра находятся в нестандартной папке, выберите папку игры один раз. При первой подготовке связки с Unity загрузчик может скачать дополнительные средства анализа; интернет потребуется для этих загрузок и облачной синхронизации игры.

Portable можно перемещать после закрытия программы. Игровые компоненты устанавливаются самостоятельно и не используют junction на папку лаунчера. Установка по умолчанию предлагается в %LOCALAPPDATA%\Programs\DivineLabs\Idle Slayer Mods (обычно на диске C:), без запроса прав администратора. Можно выбрать другое расположение.


## Папка программы

В корне находится один EXE. Portable и установленная версия используют одну структуру:

~~~
DivineLabs IdleSlayer/
├── DivineLabs.IdleSlayer.exe
├── App/
│   ├── Launcher/                  приложение и WPF-библиотеки
│   ├── Components/
│   │   ├── DivineLabs_Loader/
│   │   ├── Mods/
│   │   ├── UserLibs/
│   │   ├── Defaults/
│   │   └── manifest.json
│   └── Setup/                     удаление и сведения об установке
├── Data/                          создаётся при первом запуске
│   ├── Config/
│   ├── Cache/
│   ├── Logs/
│   └── Backups/
└── Docs/
    ├── README.ru.txt
    ├── LICENSE.txt
    ├── THIRD-PARTY-NOTICES.txt
    └── Licenses/
~~~

App/Setup добавляется установщиком. Отладочные PDB в пользовательскую поставку не входят. При обновлении 0.2.0 старые библиотеки, payload и документы сохраняются в Data/Backups/Application; известные старые файлы Data переносятся в соответствующие подпапки без перезаписи конфликтов. В корне остаются только собственные файлы пользователя, если он их добавлял.

Настройки множителей остаются в UserData игры. Defaults содержит начальные настройки компонентов, а не вторую копию пользовательского конфига.
## Использование

- Insert открывает меню; клавиша переназначается в лаунчере и игре. Есть поиск, категории, избранное и отдельные переключатели функций.
- Множитель монет применяется к положительному доходу. Цены, покупки и отрицательные списания остаются игровыми.
- Множитель урона действует в `EnemyGameObject.TakeDamage`. Отдельные механики боссов не заявлены.
- Коэффициенты: конечные числа от 1 до предела double (примерно 1.797e308); доступен ввод 1e60. Произведения, вызывающие переполнение, не применяются. По умолчанию монеты ×100, урон ×1000.
- Во время игры настройки и назначения клавиш меняются из обоих интерфейсов. Игра подтверждает изменения по локальному каналу и единолично сохраняет JSON. При потере связи неподтверждённое изменение не считается сохранённым.
- Виджет с логотипом открывает меню. В настройках можно скрыть его, изменить прозрачность и расположение. Есть режим уменьшенных анимаций.
- «Проверить / восстановить» проверяет компоненты и исправляет установку. «Запустить без модов» отключает загрузчик перед запуском через Steam.
- «Вернуть прошлую установку» возвращает предыдущие компоненты. Прогресс игры автоматически не откатывается; автоматическая подготовка после отката приостановлена до явного восстановления новой версии.

При переходе с 0.1.0 настройки импортируются, прежний `MelonLoader` сохраняется в резервной установке. Активный каталог загрузчика и каталог в поставке называются **DivineLabs_Loader**. Старые резервные копии не удаляются.

## Данные и восстановление

Настройки: `UserData/DivineLabs.settings.json` в папке игры. Схема v1 автоматически переносится в v2 с сохранением .v1.bak. Запись атомарная; последняя исправная копия сохраняется в `.bak`. Старый IdleSlayerQoL.json импортируется с сохранением оригинала.

Игровые компоненты и настройки сохраняются при обновлении. Предыдущие установки находятся в `.divinelabs-history` рядом с игрой; отключённые компоненты — в `.divinelabs-disabled`. Резервные копии сохранений находятся в папке программы `Data/Backups/Saves`. Установщик сохраняет прежние файлы приложения в `Data/Backups/Application`; при удалении программы Data и резервные копии сохраняются.

Проверенная игра: Idle Slayer 7.3.4, Steam-сборка 25810322, Unity 6000.3.14f1. При другом SHA256 игровые патчи не включаются: доступен обычный запуск.

## Репозиторий и сборка

Откройте `DivineLabs_IdleSlayer_Mods.slnx`. Структура:

| Каталог | Содержимое |
| --- | --- |
| src/Bootstrap | Автономный EXE в корне, запускающий приложение из App/Launcher |
| src/Launcher | Русский WPF-интерфейс, настройки и автоматическая подготовка |
| src/Runtime | Steam, проверка и загрузка пакета, установка, миграция и откат |
| src/Installer | NativeAOT-загрузчик и операции обслуживания; UI из общей WPF-сборки |
| src/Mod | Собственные игровые функции, меню uGUI и горячая клавиша |
| src/Contracts | Конфигурация v2, каталог функций и локальный протокол |
| src/DesktopUI | Общие стили WPF, векторный логотип и анимации |
| DivineLabs_Loader | Закреплённый форк MelonLoader с новым рабочим каталогом |
| tests | Проверки расчётов, конфигурации, загрузки и установки |
| scripts | Сборка графики, компонентов и обоих дистрибутивов |

Требования для полной сборки: .NET 10 SDK, Windows C++ Build Tools / SDK для NativeAOT, установленная игра с локальными IL2CPP-сборками. Эти игровые сборки не коммитятся и не входят в выпуск.

```powershell
./scripts/Build.ps1 -GamePath 'W:\steam\steamapps\common\Idle Slayer' -Dotnet 'W:\DEV\tools\dotnet\dotnet.exe'
dotnet run --project tests/Checks.csproj -c Release
```

В перенесённом C++ toolchain укажите `-NativeBin` и `-NativeLib`, содержащие MSVC и библиотеки Windows SDK. Полная сборка создаёт portable ZIP, Setup EXE, служебный архив компонентов для автоматической загрузки и SHA256SUMS.txt под `W:\DEV\artifacts\DivineLabs_IdleSlayer_Mods\0.4.2`. Архивы создаются из новой папки подготовки, пользовательская Data исключается. Скачиваемый пакет закреплён URL и SHA256 в src/Runtime/Resources/package-index.json.

Для проверки готовых файлов используйте scripts/CheckPortable.ps1 и scripts/CheckInstaller.ps1. Они проверяют запуск EXE, перенос portable, обновление с 0.2.0, удаление и повторную установку в изолированных папках W:\DEV\.cache\temp. Игру эти сценарии не запускают. Результаты выпуска описаны в docs/VALIDATION.md.
Служебный components.zip не является третьим вариантом программы: его скачивает лаунчер при восстановлении. Пользователь выбирает Setup или portable.

## Лицензии и происхождение

Собственные части DivineLabs — Apache-2.0. DivineLabs_Loader основан на MelonLoader 0.7.3; исходная ревизия указана в DivineLabs_Loader/UPSTREAM.txt. Сохранены оригинальные лицензии, уведомления и технические имена сборок/пространств имён. Игра, Steam и Unity сохраняют собственный брендинг. Коллекция сторонних игровых модов и IdleSlayerMods.Common не входят в поставку.

Полные уведомления находятся в THIRD-PARTY-NOTICES.txt и licenses. Там же включены соответствующие исходники Il2CppInterop (LGPL-3.0-only). Пользовательские сообщения русские; оригинальные технические исключения сохраняются в диагностическом журнале. Игра, игровые DLL, сгенерированные из игры сборки, аккаунтные данные и сохранения в выпуск не входят.
