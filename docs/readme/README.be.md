# DivineLabs Idle Slayer Mods

Мод-лаўнчар для Idle Slayer на Windows. Кіраванне гульнявымі мадыфікацыямі, наладамі і меню ў гульні.

## Спампаваць

**[Усталёўшчык](https://github.com/TheDivineLabs/DivineLabs_IdleSlayer_Mods/releases/latest/download/DivineLabs.Idle.Slayer.Mods.exe)** · **[Portable ZIP](https://github.com/TheDivineLabs/DivineLabs_IdleSlayer_Mods/releases/latest/download/DivineLabs-IdleSlayer-0.5.2-portable.zip)**

Windows x64 · Steam · Idle Slayer 7.3.4 (зборка 25810322). Асобна ўсталёўваць .NET не трэба.

![DivineLabs Idle Slayer Mods](../../assets/screenshots/launcher.png)

Лаўнчар, усталёўшчык і выдаляльнік: дзевяць моў. Гульнявое меню: руская.

## Функцыі

- Множнікі манет, урону і душ.
- Выдача рэсурсаў: манеты, SP, DP, USP і матэрыялы.
- Бясплатныя пакупкі за гульнявыя рэсурсы.
- Гульнявое меню, віджэт з перацягваннем і спіс актыўных функцый.

## Пачатак працы

1. Усталюйце Idle Slayer праз Steam.
2. Запусціце ўсталёўшчык або распакуйце portable ZIP і адкрыйце `DivineLabs.IdleSlayer.exe`.
3. Адкрыйце лаўнчар і націсніце **Гуляць**. Клавіша **Insert** адкрывае меню ў гульні.
