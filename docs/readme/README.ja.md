# DivineLabs Idle Slayer Mods

Windows向けIdle SlayerのMODランチャーです。ゲームのMOD、設定、ゲーム内メニューを管理します。

## ダウンロード

**[インストーラー](https://github.com/TheDivineLabs/DivineLabs_IdleSlayer_Mods/releases/latest/download/DivineLabs.Idle.Slayer.Mods.exe)** · **[ポータブルZIP](https://github.com/TheDivineLabs/DivineLabs_IdleSlayer_Mods/releases/latest/download/DivineLabs-IdleSlayer-0.5.2-portable.zip)**

Windows x64 · Steam · Idle Slayer 7.3.4（ビルド25810322）。.NETの別途インストールは不要です。

![DivineLabs Idle Slayer Mods](../../assets/screenshots/launcher.png)

ランチャー、インストーラー、アンインストーラー：9言語。ゲーム内メニュー：ロシア語。

## 機能

- コイン、ダメージ、ソウルの倍率変更。
- リソースの付与：コイン、SP、DP、USP、素材。
- ゲーム内リソースを使う購入の無料化。
- ゲーム内メニュー、ドラッグできるウィジェット、有効な機能の一覧。

## 使い方

1. SteamからIdle Slayerをインストールしてください。
2. インストーラーを実行するか、ポータブルZIPを展開して `DivineLabs.IdleSlayer.exe` を開きます。
3. ランチャーを開いて **プレイ** を押します。ゲーム中に **Insert** キーでメニューを開けます。
