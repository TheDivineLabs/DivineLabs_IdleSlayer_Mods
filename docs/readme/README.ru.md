# DivineLabs Idle Slayer Mods

Мод-лаунчер для Idle Slayer на Windows. Управление игровыми модификациями, настройками и меню в игре.

## Скачать

**[Установщик](https://github.com/TheDivineLabs/DivineLabs_IdleSlayer_Mods/releases/latest/download/DivineLabs.Idle.Slayer.Mods.exe)** · **[Portable ZIP](https://github.com/TheDivineLabs/DivineLabs_IdleSlayer_Mods/releases/latest/download/DivineLabs-IdleSlayer-0.5.3-portable.zip)**

Windows x64 · Steam · Idle Slayer 7.3.4 (сборка 25810322). Отдельно устанавливать .NET не нужно.

![DivineLabs Idle Slayer Mods](../../assets/screenshots/launcher.png)

Лаунчер, установщик и удалятор: девять языков. Игровое меню: русский.

## Функции

- Множители монет, урона и душ.
- Выдача ресурсов: монеты, SP, DP, USP и материалы.
- Бесплатные покупки за игровые ресурсы.
- Игровое меню, перетаскиваемый виджет и список активных функций.

## Начало работы

1. Установите Idle Slayer через Steam.
2. Запустите установщик либо распакуйте portable ZIP и откройте `DivineLabs.IdleSlayer.exe`.
3. Откройте лаунчер и нажмите **Играть**. Клавиша **Insert** открывает меню в игре.
